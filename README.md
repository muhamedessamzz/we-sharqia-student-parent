# مدارس WE للتكنولوجيا التطبيقية - الشرقية | بوابة الطلاب وأولياء الأمور
## WE Sharkia Applied Technology School - Student & Parent Portal

بوابة إلكترونية تفاعلية لطلاب وأولياء أمور مدرسة WE للتكنولوجيا التطبيقية بالشرقية. تتيح للطلاب حل التكليفات والواجبات التفاعلية، متابعة المهارات التقنية، مشاهدة الشروحات المسجلة، واستعراض الجداول المدرسية. وتوفر لأولياء الأمور متابعة درجات أبنائهم، سجل الحضور، الإشعارات السلوكية، وإرسال الطلبات الإدارية.

---

### 🚀 المميزات الرئيسية (Core Features):
- **بوابة الطالب (Student Portal):**
  - منصة (جاهز · استعد · سلّم) لحل التكليفات والواجبات على 3 مراحل تصاعدية الصعوبة.
  - الجدول الأسبوعي للحصص والمعامل المتخصصة.
  - مكتبة الفيديوهات التعليمية المسجلة.
  - متابعة المهارات الرقمية ونظام الشارات والنجوم.
- **بوابة ولي الأمر (Parent Portal):**
  - متابعة الأداء الدراسي ونسب الحضور والغياب.
  - الإشعارات المدرسية والتنبيهات السلوكية مع إمكانية تأكيد الاستلام.
  - تقديم ومتابعة الطلبات الموجهة لإدارة المدرسة.
  - طباعة شهادة تقرير درجات الطالب الرسمية (Printable Report Card).

---

### 💻 التقنيات المستخدمة (Tech Stack):
- **Frontend:** React 19 + Vite + Tailwind CSS
- **Icons & UI:** Lucide React
- **Backend API:** ASP.NET Core Clean Architecture
- **Database:** Microsoft SQL Server

---

### ⚙️ التشغيل محلياً (Run Locally):
```bash
# تثبيت الاعتماديات
npm install

# تشغيل خادم التطوير
npm run dev
```

---

### 🌐 النشر (Deployment):
مهيأ للنشر المباشر على **Vercel** بواسطة [`vercel.json`](./vercel.json) المدمج مع Reverse Proxy للاتصال الآمن بالباك إند.
